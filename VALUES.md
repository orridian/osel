# Values

Each value is paired with behaviors that demonstrate it. A value without behaviors is decoration.

| Value | Behaviors that demonstrate it |
|---|---|
| **Correctness** | Every user-visible change ships with tests. Statistical methods are checked against reference calculations. Deterministic fixtures have known expected outputs. |
| **Transparency** | Decisions are written in the [decision log](operations/decision-log.md). Roadmap dates are labelled as targets. Benchmark methodology is published with results. |
| **Respect** | The [Code of Conduct](CODE_OF_CONDUCT.md) is enforced. Disagreement targets ideas, not people. Contributors are told what happened to their contribution. |
| **Accessibility** | The website and docs are keyboard-navigable and meet contrast guidelines. Examples are short and runnable. Workshop materials have written guides. |
| **Privacy** | No telemetry by default. Run records never capture environment variables or secrets. Public issues never ask for credentials or private data. |
| **Sustainability** | Scope is frozen when the core workflow is at risk. School, sleep and health are constraints, not resources. Every component has an owner and a maintenance plan. |
| **Evidence-based decisions** | Product choices cite user evidence. Metrics have written definitions ([METRICS.md](METRICS.md)). Claims without evidence are not published. |
