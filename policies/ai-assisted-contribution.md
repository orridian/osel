# AI-assisted contribution policy

**Owner:** Maintainers · **Review:** every 6 months · **Questions:** GitHub Discussions · **Enforcement:** PRs that break these rules are closed; repeated bulk low-quality PRs may lead to restriction under the Code of Conduct.

1. **Human responsibility.** You are responsible for every line you submit, whatever tool produced it. You must be able to explain it in review.
2. **Testing.** AI-assisted code meets the same test requirements as any other code. Run the tests yourself.
3. **Disclosure.** Disclose substantial generated work (beyond autocomplete-sized snippets) in the PR template's AI section.
4. **No fabricated attribution.** Do not invent references, benchmark numbers, citations, issue links or co-authors.
5. **No bulk low-quality PRs.** Mass-generated PRs (typo sweeps, speculative refactors, auto-"fixes" of non-issues) are closed without detailed review.
6. **License review.** Do not submit generated output that reproduces third-party code with an incompatible license. If you have reason to believe it does, say so.
7. **Privacy.** Do not paste private datasets, other people's personal data or security reports into third-party AI tools.
