# Benchmarks

Reproducible performance and evaluation studies. These are **not** marketing tests.

**No benchmark claims are published yet.** Each study will live in its own folder, following the [Reproducibility Program](../programs/reproducibility-program.md) and the [benchmark integrity policy](../policies/benchmark-integrity.md):

```text
benchmarks/<study>/
  PROTOCOL.md    # committed before the main run
  README.md      # exact rerun instructions on a clean machine
  configs/       # osel configs
  runs/          # osel run records (dataset identity, versions, environment)
  RESULTS.md     # results, limitations, deviations, verification label
```
