# Operations

How OSEL is run day to day. These files are **public templates and processes**.
Anything containing personal data (interview notes, metric evidence, conduct or security reports, the founder evidence archive) lives in a **private** location outside this repository, such as a private repo or drive folder shared with a parent/guardian. It never lives here. `private/` is git-ignored as a safety net.
