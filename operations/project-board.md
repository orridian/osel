# Project board

**Columns:** Backlog → Ready → In Progress → Review → Blocked → Done

- **Ready** means the item has a problem statement, acceptance criteria and an owner.
- WIP limit: 3 items in progress at once.
- Blocked items say what they are waiting for.

Create it in GitHub Projects once the organization exists. Add a "Status" single-select field with the six columns.
