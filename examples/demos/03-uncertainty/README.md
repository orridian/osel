# Demo 3 — Statistical uncertainty

**Claim:** comparing two averages alone can mislead. The *same* improvement can be indistinguishable from noise on a small test set, yet clearly supported on a larger one.

Both scenarios have **exactly the same accuracy change: 70% → 75%** (data generated by `generate.py`):

| Scenario | Examples | Candidate fixes | Candidate breaks |
|---|---|---|---|
| `small/` | 40 | 4 | 2 |
| `large/` | 400 | 40 | 20 |

```bash
cd examples/demos/03-uncertainty/small
osel eval run baseline.yaml -o b.json && osel eval run candidate.yaml -o c.json
osel compare b.json c.json
# then the same in ../large
```

**Small (40 examples):**

```text
  exact_match         0.7000    0.7500   +0.0500         [-0.0750, 0.1500]  IMPROVED (CI includes 0)
```

**Large (400 examples):**

```text
  exact_match         0.7000    0.7500   +0.0500          [0.0150, 0.0850]  IMPROVED
```

## How to read this

- With 40 examples, the net gain is just 2 examples (4 fixed − 2 broken). The paired 95% interval runs from −7.5 to +15 points, so this data can't tell an improvement from noise.
- With 400 examples, the net gain is 20 examples, and the interval (+1.5 to +8.5 points) excludes zero.
- **The averages are identical in both cases.** Only the uncertainty tells them apart.

## What the interval does not tell you

It assumes the examples are independent and representative of what you care about. It says nothing about inputs unlike your test set, and a single run doesn't capture randomness inside the model. See `docs/statistics.md`.
