# Event checklist

Follows the [community event policy](../../policies/community-events.md).

## 2 weeks before
- [ ] Date and time published **with time zones**
- [ ] Registration collects only name/handle + email (+ optional accessibility needs)
- [ ] Code of Conduct linked on the registration page
- [ ] Named moderator (not the presenter). Adult supervisor present if any participant is under 18
- [ ] Recording decision announced, with how to opt out

## 3 days before
- [ ] Setup instructions sent; dry run done on a clean machine
- [ ] Slides shared in advance (accessibility)
- [ ] Captions enabled (platform auto-captions at minimum) or transcript planned

## Day of
- [ ] Meeting link not posted publicly if minors attend
- [ ] Opening slide: CoC, recording notice, how to report concerns
- [ ] Breaks scheduled
- [ ] **Backup plan:** a pre-recorded walkthrough and a hosted copy of the expected outputs in case installs fail; a backup host if the presenter's connection drops

## After
- [ ] Record registered / attended / completed counts
- [ ] Delete accessibility notes within 30 days
- [ ] Send the follow-up
