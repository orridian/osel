# University / research group engagement

> Formal agreements, data access, funding and institutional commitments require **appropriate adult and institutional oversight**. A sent message is never counted as a collaboration.

| Stage | Required action | Evidence | Tracker status |
|---|---|---|---|
| Identify | Find a relevant group and read its recent work | Research notes with the specific overlap | |
| Prepare | Create a short demo and a clear evaluation question | Working demo + one-page brief (template below) | |
| Contact | Send a personalized, low-pressure request for evaluation or feedback | Sent message (**not** counted as collaboration) | |
| Pilot | Agree scope, software version, duration and feedback method | Written scope + named contact | |
| Evaluate | Record issues, results, limitations and changes | Evaluation notes + issue links | |
| Publish | Get permission and review attribution | Approved case study or research output | |

## One-page brief template

- **What osel is** (2 sentences, alpha status stated):
- **Why this group** (the specific overlap with their published work):
- **The question we'd like help answering:**
- **What we're asking for:** e.g. 1 hour to try the quick start on one of their evaluations, plus a 20-minute feedback call
- **What we're not asking for:** money, data sharing, endorsement, or co-authorship
- **Contact:** role address
